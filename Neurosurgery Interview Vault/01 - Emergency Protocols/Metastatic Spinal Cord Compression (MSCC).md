# Metastatic Spinal Cord Compression (MSCC)

## Overview

Oncological emergency requiring urgent diagnosis and treatment within 24 hours. MSCC affects 5-10% of cancer patients and is often the first presentation of malignancy. Early recognition and treatment are critical to preserve neurological function.

**Source**: Cambridge University Hospitals NHS Foundation Trust (Version 1, December 2021)

---

## Initial Assessment & Management

### Immediate Actions

**If neurological deficit suspected:**

1. **Start Dexamethasone 8mg BD** stat
   - With PPI cover (omeprazole 20mg OD or equivalent)
   - **Contraindication**: Signs of sepsis (risk of fungal infection with high-dose steroids)

2. **MRI whole spine within 24 hours** unless contraindicated
   - Available at weekends at most DGHs
   - QEH Kings Lynn: Saturday 9-12 only

3. **Refer to MSCC Coordinator**
   - CUH: Oncology SpR on call
   - DGH: Local Oncology/Acute Oncology Service (AOS) team

## Clinical Presentation

### Red Flag Symptoms
- **Back pain** (present in 95%)
  - New onset or worsening
  - Worse at night
  - Mechanical pain (worse with standing/walking)
- **Motor weakness** (75% at presentation)
- **Sensory changes** (50%)
- **Sphincter dysfunction** (50% at diagnosis)
- **Gait disturbance**

### Neurological Examination
**Assess Frankel Grade** (for prognostication):

| Grade | Description | Motor | Sensory |
|-------|-------------|-------|---------|
| **A** | Complete | Absent below lesion | Absent below lesion |
| **B** | Sensory only | Absent | Preserved |
| **C** | Motor useless | Present but non-functional | Preserved |
| **D** | Motor useful | Functional but weak | Preserved |
| **E** | Normal | Normal | Normal |

## Imaging

### MRI Whole Spine (Gold Standard)
**Indications:**
- Any patient with known cancer + new neurological signs/symptoms
- Back pain in cancer patient with:
  - Spinal tenderness
  - Nocturnal pain
  - Progressive pain despite analgesia

**Sequences Required:**
- T1 (anatomy, vertebral body involvement)
- T2 (cord signal, soft tissue)
- STIR (oedema, metastases)
- T1 + gadolinium (if available)

**Why whole spine?**
- 10-38% have multiple non-contiguous levels
- Identifies optimal treatment level

## Decision-Making Scores

### 1. Tokuhashi Score (Prognosis)

**Purpose**: Predict survival to guide treatment intensity

| **Factor** | **Score** |
|------------|-----------|
| **General condition (Performance Status)** | |
| Poor (PS 10-40%) | 0 |
| Moderate (PS 50-70%) | 1 |
| Good (PS 80-100%) | 2 |
| **Number of extraspinal bone metastases** | |
| ≥3 | 0 |
| 1-2 | 1 |
| 0 | 2 |
| **Number of vertebral body metastases** | |
| ≥3 | 0 |
| 1-2 | 1 |
| 0 | 2 |
| **Metastases to major internal organs** | |
| Unremovable | 0 |
| Removable | 1 |
| No metastases | 2 |
| **Primary site** | |
| Lung, osteosarcoma, stomach, bladder, oesophagus, pancreas | 0 |
| Liver, gallbladder, unidentified | 1 |
| Others | 2 |
| Kidney, uterus | 3 |
| Rectum | 4 |
| Thyroid, breast, prostate, carcinoid | 5 |
| **Palsy (Frankel grade)** | |
| Complete (A, B) | 0 |
| Incomplete (C, D) | 1 |
| None (E) | 2 |

**Interpretation:**
- **0-8 points**: Predicted survival <6 months
- **9-11 points**: Predicted survival 6-12 months
- **12-15 points**: Predicted survival ≥1 year

**Note**: Tokuhashi score can be **overridden by oncology team** based on:
- Known biology of primary tumour
- Response to systemic therapy
- Patient/family wishes

### 2. SINS Score (Spinal Instability)

**Purpose**: Assess mechanical stability of spine

| **Component** | **Score** |
|---------------|-----------|
| **Location** | |
| Junctional (occiput-C2, C7-T2, T11-L1, L5-S1) | 3 |
| Mobile spine (C3-C6, L2-L4) | 2 |
| Semirigid (T3-T10) | 1 |
| Rigid (S2-S5) | 0 |
| **Pain** | |
| Yes (mechanical pain) | 3 |
| Occasional pain but not mechanical | 2 |
| Pain-free lesion | 0 |
| **Bone lesion type** | |
| Lytic | 2 |
| Mixed (lytic/blastic) | 1 |
| Blastic | 0 |
| **Spinal alignment** | |
| Subluxation/translation present | 4 |
| De novo deformity (kyphosis/scoliosis) | 2 |
| Normal alignment | 0 |
| **Vertebral body collapse** | |
| >50% collapse | 3 |
| <50% collapse | 2 |
| No collapse with >50% body involved | 1 |
| None of above | 0 |
| **Posterolateral involvement*** | |
| Bilateral | 3 |
| Unilateral | 1 |
| None | 0 |

*Facet, pedicle, or costovertebral joint fracture/replacement with tumour

**Interpretation:**
- **0-6**: Stable spine
- **7-12**: Potentially unstable (consider surgical consultation)
- **13-18**: Unstable spine (**bed rest mandatory** until surgical review)

**Clinical Action:**
- **SINS >13 or mechanical pain on mobilization**:
  - **Bed rest** until spinal surgeon review
  - Risk of neurological deterioration with mobilization

## Treatment Pathways

### Surgical Referral Criteria

**Contact neurosurgery** if meets ALL of the following:

1. **Prognosis >6 months** (Tokuhashi score typically >8)
   - Can be overridden by oncology team

**AND one or more of:**

2. **Spinal instability** (SINS score ≥7)
3. **Limited spinal disease** (single or few levels)
4. **Previously irradiated area** with no scope for further RT
5. **Bony/compressive lesion** (not radiosensitive soft tissue compression)
6. **Unknown primary** requiring tissue diagnosis

**Additional considerations for surgery:**
- Neurological deterioration <24 hours (relative emergency)
- Frankel C/D/E (incomplete lesions have better surgical outcomes)
- Life expectancy and quality of life goals

**Patients NOT meeting criteria:**
- Remain under oncology/palliative care
- May still receive radiotherapy for symptom control

**Frankel A/B for >24-48 hours:**
- Surgery unlikely to restore function
- Radiotherapy has limited benefit but can provide pain control
- Focus on palliative care

## Radiotherapy Protocols

### Standard Regimens

| **Clinical Scenario** | **Dose/Fractionation** |
|----------------------|------------------------|
| **Standard treatment** | **8Gy single fraction** |
| **Good prognosis/new diagnosis** | **20Gy in 5 fractions** (Mon-Fri) |
| **Re-treatment** | **16Gy in 4 fractions** |

### Weekend Radiotherapy (Emergency)

**Available**: Saturday and Sunday 10:00-12:00

**Standard prescription**:
- **8Gy to 6cm depth**
- 998MU of 10MV x-rays at 100cm FSD
- Use preset "on-call RT prescription"

**If planning 20Gy/5 fractions course**:
- Give **4Gy at weekend** (450MU at 100cm FSD)
- State depth required on prescription
- Full plan calculated Monday for remainder
- **Must clearly document** "20Gy in 5 fractions" on prescription

---

### Post-Surgical Radiotherapy
- **Timing**: Once wound healed and patient discharged home
- **Indications**:
  - Incomplete tumour resection
  - High-grade histology
  - Microscopic residual disease
- **Regimen**: Typically 20Gy/5# or 30Gy/10# depending on prognosis

## Dexamethasone Protocol

### Initial Dosing
**Standard**:
- **8mg BD** (16mg total daily)
- With PPI cover (omeprazole 20mg OD or lansoprazole 30mg OD)

**Higher dose (16mg BD)** may be considered for:
- Rapid neurological deterioration
- Complete paralysis <24 hours
- Consultant decision only

### Contraindications
- **Active sepsis** (risk of disseminated fungal infection)
- **Uncontrolled diabetes** (relative - balance benefit vs risk)
- **Gastric ulcer** (use higher-dose PPI)

### Monitoring
- Blood glucose (QDS if diabetic, BD if not)
- Watch for: steroid psychosis, insomnia, gastritis, hyperglycaemia

### Weaning
**After radiotherapy or surgery:**
- Wean over 2-4 weeks depending on response
- Typical taper: 8mg BD → 4mg BD → 2mg BD → 2mg OD → stop
- If symptoms recur: step back up and wean more slowly

## Surgical Options

### 1. Decompression Alone
**Indications:**
- Stable spine (SINS 0-6)
- Soft tissue compression only
- Good bone quality

**Approaches:**
- Laminectomy (posterior approach)
- Rarely used alone due to risk of destabilization

### 2. Decompression + Stabilization
**Indications (most common approach):**
- Unstable spine (SINS ≥7)
- Vertebral body involvement
- Post-laminectomy instability risk

**Techniques:**
- Posterior instrumented fusion (pedicle screws + rods)
- May include laminectomy/corpectomy

### 3. Separation Surgery
**Modern technique for MSCC:**
- Posterior approach
- Decompress cord + stabilize with instrumentation
- Create space between cord and tumour
- **Allows for higher-dose SBRT** (stereotactic body radiotherapy) post-op
- Increasingly preferred over extensive resection

### 4. Corpectomy + Reconstruction
**Indications:**
- Isolated vertebral body disease
- Acceptable surgical risk
- Good prognosis (>1 year)

**Technique:**
- Anterior or posterior approach
- Vertebrectomy
- Cage + cement reconstruction
- Stabilization

## Outcomes & Prognostic Factors

### Factors Predicting Ambulatory Outcome

**Positive Predictors:**
- Pre-treatment ambulatory status (strongest predictor)
- Short duration of symptoms (<24 hours better than >weeks)
- Incomplete neurological deficit (Frankel C/D)
- Radiosensitive tumour (myeloma, lymphoma, prostate, breast)
- Single level disease
- Good performance status

**Poor Predictors:**
- Complete paralysis (Frankel A/B) >48 hours
- Rapid progression (<24 hours to complete paralysis)
- Multiple levels
- Poor performance status
- Visceral metastases

### Ambulatory Rates Post-Treatment

**Pre-treatment ambulatory:**
- 85-90% remain/regain ambulation

**Pre-treatment non-ambulatory (Frankel C/D):**
- ~50% regain ambulation (better with surgery than RT alone)

**Pre-treatment paraplegic (Frankel A/B):**
- ~10-15% regain ambulation if treated <24 hours
- <5% if paraplegic >48 hours

## Specific Tumour Types

### Radiosensitive (RT First-Line)
- **Myeloma**
- **Lymphoma**
- **Small cell lung cancer**
- **Germ cell tumours**

**Management:** Radiotherapy ± chemotherapy

### Moderately Radiosensitive
- **Breast cancer**
- **Prostate cancer**
- **Thyroid cancer**

**Management:** Surgery if unstable/bony compression; RT otherwise

### Radioresistant (Surgery Preferred)
- **Renal cell carcinoma**
- **Melanoma**
- **Sarcoma**
- **Colorectal cancer**

**Management:** Surgery if fit; RT for symptom control only

## Complications

### Of MSCC Itself
- **Permanent paralysis**
- **Sphincter dysfunction** (neurogenic bladder/bowel)
- **Neuropathic pain**
- **Pressure sores** (immobile patients)
- **DVT/PE** (25% risk in paraplegic patients)
- **Psychological impact**

### Of Treatment

**Surgery:**
- Wound infection (5-10%)
- CSF leak
- Neurological deterioration (5%)
- Instrumentation failure
- Medical complications (MI, PE, pneumonia)

**Radiotherapy:**
- Acute: oesophagitis (thoracic spine), diarrhoea (lumbar), skin reaction
- Late: radiation myelopathy (rare with modern techniques <1%)
- Vertebral fracture (pathological, post-RT)

**Steroids:**
- Hyperglycaemia
- Gastritis/perforation
- Psychosis
- Proximal myopathy
- Immunosuppression

## Multidisciplinary Team Roles

### MSCC Coordinator (MSCCC)
**Responsibilities:**
- Central point of contact
- Coordinate imaging within 24 hours
- Liaise between oncology, neurosurgery, radiotherapy
- Ensure prognosis documented before neurosurgical referral
- Track pathway compliance

**Who:**
- CUH: Oncology SpR on call
- DGH: Local Oncology/AOS team (weekdays); CUH Oncology SpR (weekends)

### Oncology Team
- Assess prognosis (Tokuhashi score)
- Determine suitability for systemic therapy
- Coordinate radiotherapy
- **Must review before neurosurgical referral**

### Neurosurgery
- Assess surgical candidacy
- Perform decompression/stabilization
- Provide opinion even if surgery not undertaken (document reasoning)

### Palliative Care
- Symptom control (pain, nausea)
- Advance care planning
- End-of-life care if prognosis <6 months and not surgical candidate

## Key Evidence Base

### Landmark Trials

1. **Patchell et al. (2005)** - Lancet 366: 643-648
   - RCT: Surgery + RT vs RT alone for MSCC
   - **Result**: Surgery superior for maintaining/regaining ambulation (84% vs 57%)
   - **Conclusion**: Surgery + RT is gold standard for single-level MSCC in fit patients with reasonable prognosis

2. **Rades et al. (2010)** - Cancer 116: 3064-3069
   - Meta-analysis: 8Gy vs 20Gy for MSCC
   - **Result**: No significant difference in ambulatory rate or survival
   - **Conclusion**: 8Gy single fraction effective for most patients; 20Gy for longer life expectancy

3. **Fisher et al. (2010)** - JAMA 303: 1343-1349
   - Spine Instability Neoplastic Score (SINS) development
   - **Result**: SINS ≥13 highly predictive of mechanical instability
   - **Conclusion**: SINS useful screening tool for surgical referral

4. **Tokuhashi et al. (2005)** - Spine 30: 2151-2156
   - Revised Tokuhashi score for survival prediction
   - **Accuracy**: ~80% for predicting <6 months vs >1 year survival
   - **Use**: Guide treatment intensity

## Interview Key Points

### Management Principles
1. **Oncological emergency** - 24-hour pathway for diagnosis and treatment
2. **Dexamethasone 8mg BD stat** (with PPI) if no sepsis
3. **MRI whole spine within 24 hours**
4. **Multidisciplinary decision-making** (oncology, neurosurgery, radiotherapy)
5. **Prognosis** (Tokuhashi) and **spinal stability** (SINS) guide treatment
6. **Pre-treatment mobility** strongest predictor of outcome
7. **Bed rest if SINS >13** or mechanical pain

### Treatment Algorithm
- **Good prognosis + unstable spine/bony compression** → Surgery + RT
- **Good prognosis + radiosensitive tumour** → RT (± chemotherapy)
- **Poor prognosis** → RT for symptom control or palliative care
- **Complete paralysis >48 hours** → RT for pain control; surgery unlikely to help

## Common Interview Questions

**Q: What is MSCC and why is it an emergency?**
A: Malignant spinal cord compression - compression of the spinal cord by metastatic tumour (extradural in 95%). Emergency because neurological deficit becomes irreversible if not treated within 24-48 hours. Pre-treatment mobility is the strongest predictor of post-treatment mobility.

**Q: What is the initial management of suspected MSCC?**
A:
1. **Dexamethasone 8mg BD** stat (with PPI) unless septic
2. **MRI whole spine** within 24 hours (10-38% have non-contiguous levels)
3. **Refer to MSCC Coordinator** for pathway activation
4. **Bed rest** if mechanical pain or SINS >13 (unstable spine)

**Q: What is the Tokuhashi score?**
A: Prognostic score predicting survival in MSCC patients. Six factors scored 0-2:
- General condition (performance status)
- Number of extraspinal bone metastases
- Number of vertebral metastases
- Visceral metastases
- Primary tumour site
- Frankel grade (paralysis)

**Total**: 0-8 (<6 months), 9-11 (6-12 months), 12-15 (>1 year)

**Used to decide treatment intensity**: Surgery typically considered if score >8 (prognosis >6 months)

**Q: What is the SINS score?**
A: Spinal Instability Neoplastic Score - assesses mechanical stability. Six factors:
- Location (junctional areas highest risk)
- Pain character (mechanical pain scores higher)
- Bone lesion type (lytic > mixed > blastic)
- Spinal alignment (subluxation/deformity)
- Vertebral body collapse (>50% highest risk)
- Posterolateral involvement (facets/pedicles)

**Interpretation**:
- 0-6: Stable
- 7-12: Potentially unstable (consider surgery)
- 13-18: Unstable (**bed rest mandatory**, surgical referral)

**Q: What are the indications for surgical referral in MSCC?**
A: Contact neurosurgery if **prognosis >6 months** AND one or more of:
- Spinal instability (SINS ≥7)
- Limited spinal disease
- Previously irradiated area (no further RT possible)
- Bony/compressive lesion (not radiosensitive soft tissue)
- Unknown primary requiring biopsy

Also consider if **neurological deterioration <24 hours** regardless of other factors.

**Q: What is the evidence for surgery in MSCC?**
A: **Patchell et al. (Lancet 2005)**: RCT of surgery + RT vs RT alone.
- **Results**: Surgery group had superior ambulatory outcomes (84% vs 57%), longer time to losing ambulation, and longer survival
- **Patients**: Single-level MSCC, fit for surgery, reasonable prognosis
- **Conclusion**: Surgery + RT is standard of care for appropriate candidates

**Caveat**: Most benefit in patients ambulatory pre-treatment or recently non-ambulatory (<48 hours)

**Q: What radiotherapy regimens are used for MSCC?**
A:
- **Standard**: 8Gy single fraction (equivalent efficacy to longer courses, convenient)
- **Good prognosis**: 20Gy in 5 fractions (may provide longer-term control)
- **Re-treatment**: 16Gy in 4 fractions (depends on prior dose and spinal cord tolerance)
- **Weekend emergency**: 8Gy single fraction available Sat/Sun 10-12

**Evidence**: Meta-analyses show no difference in ambulatory rate between 8Gy and 20Gy. 8Gy preferred for convenience unless long life expectancy expected.

**Q: Why do you give dexamethasone in MSCC?**
A: High-dose steroids reduce spinal cord oedema and inflammation from compression. **Benefits**:
- Reduce pain
- Preserve neurological function
- Bridge to definitive treatment (surgery/RT)

**Dose**: 8mg BD (16mg total daily) with PPI cover

**Evidence**: Observational data suggests benefit, though no RCTs. Widely accepted standard of care.

**Contraindication**: Sepsis (risk of disseminated fungal infection)

**Q: What factors predict ambulatory outcome after MSCC treatment?**
A: **Strongest predictor**: Pre-treatment ambulatory status
- Ambulatory pre-treatment → 85-90% remain ambulatory
- Non-ambulatory (Frankel C/D) → ~50% regain ambulation (higher with surgery)
- Complete paralysis (Frankel A/B) >48 hours → <5% regain ambulation

**Other positive factors**:
- Rapid treatment (<24 hours from symptom onset)
- Radiosensitive tumour (myeloma, lymphoma, breast, prostate)
- Good performance status
- Single level disease

**Q: What is the role of bed rest in MSCC?**
A: **Mandatory** bed rest if:
- **SINS score ≥13** (unstable spine)
- **Mechanical pain** (pain worse with standing/walking)

**Rationale**: Prevent catastrophic neurological deterioration from spinal instability or vertebral collapse during mobilization.

**Duration**: Until spinal surgeon review and imaging assessment. If surgery planned, continue bed rest until stabilization. If RT planned and SINS <13, may mobilize with caution.

**Q: How do you manage a patient with complete paralysis for 48 hours?**
A: **Realistic prognosis discussion** - very unlikely to regain function (<5% chance)

**Management options**:
1. **Radiotherapy** for pain control (8Gy single fraction)
2. **Palliative care** focus - pressure care, bladder/bowel management, psychological support
3. **Surgery** generally not indicated (won't restore function; high complication risk in paraplegic patient)

**Important**: Involve patient/family in shared decision-making about goals of care

**Q: What is separation surgery?**
A: **Modern neurosurgical technique** for MSCC:
- Posterior approach
- Decompress spinal cord (laminectomy ± partial corpectomy)
- Stabilize with instrumentation (pedicle screws + rods)
- Create space ("separation") between tumour and spinal cord
- **Allows subsequent high-dose stereotactic body radiotherapy (SBRT)**

**Advantages over traditional extensive resection**:
- Less morbidity
- Shorter operative time
- Enables SBRT (better tumour control than conventional RT)
- Good functional outcomes

**Increasingly preferred approach** in modern spinal oncology

## Key Takeaways for Viva

1. **24-hour emergency** - Dexamethasone + MRI whole spine + MSCC Coordinator
2. **Pre-treatment mobility** strongest predictor of outcome - **treat early**
3. **Tokuhashi** (prognosis) and **SINS** (stability) scores guide treatment
4. **Bed rest if SINS ≥13** or mechanical pain
5. **Surgery + RT** superior to RT alone in fit patients (Patchell 2005)
6. **8Gy single fraction** effective for most patients
7. **Paraplegic >48 hours** - unlikely to recover; focus on palliation
8. **Radiosensitive tumours** (myeloma, lymphoma) - RT first-line
9. **Radioresistant tumours** (renal, melanoma) - surgery preferred if fit
